# Dokumentasi Sistem Penjadwalan Otomatis

## Cara Install

1. Clone repository
2. Copy .env.example menjadi .env
3. Edit konfigurasi database di .env
4. Jalankan: php artisan migrate --seed
5. Jalankan: npm run dev
6. Akses: http://localhost:8000
